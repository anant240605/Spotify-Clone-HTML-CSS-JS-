# 🎵 Spotify Clone (Frontend)

A simple **Spotify-inspired music player** built using **HTML, CSS, and vanilla JavaScript**.  
This project is completely **client-side** and created for learning and practice purposes.  
It is **not an exact clone** of Spotify.
 🚀 Features
- Play / Pause songs  
- Next & Previous track controls  
- Progress bar with seek functionality  
- Song duration & current time display  
- Dynamic song list rendering  
- Responsive and clean UI  

🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript (Client-side)

📂 Project Type
Frontend-only project (No backend, No database)

 🎯 Purpose
This project was built to improve understanding of:
- DOM manipulation  
- JavaScript event handling  
- Audio API  
- UI interaction logic  


⚠️ Disclaimer
This project is made for **educational purposes only** and is not affiliated with or endorsed by Spotify.

---
💡 How to Run
1. Clone the repository  
2. Open `index.html` in your browser  
3. Enjoy 🎶
